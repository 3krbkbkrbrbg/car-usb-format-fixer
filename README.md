# Car USB Format & Repair 🚗🎵

اپلیکیشن اندرویدی برای تبدیل خودکار فرمت فلش مموری و کارت حافظه به استاندارد ضبط خودرو (FAT32) **بدون حذف آهنگ‌ها**.

## ✨ امکانات
- **تشخیص خودکار اتصال (Auto-detect):** نمایش گزینه‌های تعمیر و فرمت به محض اتصال کابل OTG یا فلش.
- **تبدیل امن (Zero Data Loss):** پشتیبان‌گیری موقت از موزیک‌ها، اعمال فرمت FAT32 سازگار با ضبط و بازگردانی سریع فایل‌ها.
- **رفع خطای ضبط‌های ماشین:** پاک‌سازی فایل‌های مخرب Mac/Windows (`._*`, `.DS_Store`, `Thumbs.db`) که باعث خطای Error-23 یا رد شدن آهنگ می‌شوند.
- **تعمیر تخصصی ضبط ۲۰۶ و ایران‌خودرو (حل مشکل پریدن روی رادیو):** رفع خطای رایج سیستم‌های صوتی ۲۰۶ (کروز/موج‌نیکان) که فلش را شناسایی نکرده و به رادیو سوئیچ می‌کنند؛ از طریق فلت‌سازی ساختار پوشه‌ها، حذف فایل‌های مخفی `System Volume Information` و `._*` و تصحیح فرمت کلاستر به FAT32 استاندارد خودرو.
- **تبدیل همگانی آهنگ‌ها به MP3 (Universal Audio Converter):** جستجوی تمام فایل‌های صوتی داخل فلش (M4A, AAC, WAV, FLAC, OGG, WMA) و تبدیل به MP3 استاندارد قابل پخش در انواع ضبط‌های قدیمی و جدید بدون افت کیفیت و تغییر حجم.
- **اصلاح تگ‌ها و ساختار نام‌گذاری صوتی:** تنظیم کاراکترها برای نمایش صحیح نام آهنگ روی صفحه نمایش ماشین.
